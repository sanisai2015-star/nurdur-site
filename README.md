# NURDAR Al Faisal Website (AR/EN)

Starter source for **nurduralfaisal.com** with:
- Next.js (App Router)
- TailwindCSS
- Framer Motion (reveal + hero motion)
- Locale routing: `/ar` and `/en` (default redirects to `/ar`)
- Brand colors: **Blue + Gold**
- WhatsApp: 00447777777
- Facebook: nurduralfaisal

## Run locally
```bash
npm install
npm run dev
```

## Assets
- Logo: `public/logo.jpg`
- Project images: `public/projects/`
  - Extracted 150 images from PDF into public/projects/.
